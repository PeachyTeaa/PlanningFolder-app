# PlanningFolder

Заметки и планирование проектов для команд.

- **Веб-версия:** https://peachyteaa.github.io/PlanningFolder-app/
- **Windows и Android:** [последний релиз](https://github.com/PeachyTeaa/PlanningFolder-app/releases/latest) — `PlanningFolder.exe` (один файл, просто запустить) и `PlanningFolder.apk` (установить на телефон).

Обновление — кнопкой «Обновить» в самом приложении (Профиль → О приложении).

Здесь лежат только готовые сборки; ветка `gh-pages` публикуется автоматически.
